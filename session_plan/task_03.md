Title: Make generated skill scaffolds actionable by default
Files: src/nanobot/skills/skill-creator/scripts/init_skill.py, tests/unit/test_init_skill.py
Issue: none

Tighten the skill scaffold generated by `src/nanobot/skills/skill-creator/scripts/init_skill.py` so it stops shipping the most obvious unresolved placeholders from the assessment. Keep this task small and localized: improve `SKILL_TEMPLATE` so the first main section is a concrete default heading instead of a TODO placeholder, and make the CLI’s next-step guidance in `init_skill` reflect only the resource directories the user actually selected.

Add targeted tests in `tests/unit/test_init_skill.py` that create a skill in a temp directory, inspect the generated `SKILL.md`, and verify the follow-up output is specific to the chosen resources. The point is to make the scaffold more usable for new capabilities without redesigning the tool.

Verify with `python3 -m pytest tests/unit/test_init_skill.py -q`.
