# Dify Chat API Skill

这是一个专门用于调用Dify API进行对话查询的技能。该技能可以发送查询到Dify聊天系统，获取AI回答，支持流式响应。

## 使用方法

1. **调用技能**，告诉我要查询什么问题
2. **提供查询内容**（比如"bgp怎么配"）
3. **获取Dify AI的回答**

## 核心功能

- **💬 智能对话**: 发送查询到Dify系统获取AI回答
- **🌊 流式响应**: 支持实时流式输出响应内容
- **🔧 网络技术**: 专门针对网络设备配置、故障处理等技术问题
- **⚡ 快速响应**: 直接调用API，无需额外配置

## 支持的查询类型

- **网络配置**: BGP、OSPF、VLAN、路由等配置问题
- **故障排查**: 网络设备故障诊断和处理方法
- **技术文档**: 网络架构、最佳实践、操作指南
- **设备管理**: 交换机、路由器等网络设备管理

## 技能工作流程

1. 理解用户查询问题
2. 构建Dify API请求参数
3. 调用Dify聊天API
4. 处理流式响应
5. 格式化并返回AI回答

## 执行指令

当用户请求查询技术问题时：

1. **理解查询意图**:
   - 提取用户的核心问题
   - 识别技术领域（网络配置、故障排查等）

2. **API参数构建**:
   ```json
   {
     "inputs": {},
     "query": "用户的具体问题",
     "response_mode": "streaming",
     "user": "louiszcwang"
   }
   ```

3. **API调用**:
   - URL: `http://api.dify.woa.com/v1/chat-messages`
   - Method: `POST`
   - Headers:
     - `Authorization: Bearer app-HgRTR9OjB`
     - `Content-Type: application/json`

4. **响应处理**:
   - 解析流式响应
   - 提取AI回答内容
   - 格式化输出给用户

## 注意事项

- API使用流式响应模式，可以实时获取回答
- 当前固定用户为"louiszcwang"
- 专门优化用于网络技术相关问题
- 支持中文查询和回答
- API端点和认证信息已预配置
