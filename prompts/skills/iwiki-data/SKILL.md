# iWiki Knowledge Retrieval Skill

这是一个专门用于从NOSGPT_IWIKI系统获取知识库信息的技能。该技能可以搜索文档、获取文档内容、查询空间信息等，用于访问网络架构图、SOP、故障处理手册等技术文档。

## 使用方法

1. **调用技能**，告诉我要查询什么信息或搜索什么内容
2. **提供查询参数**（关键词、文档ID、空间名称等）
3. **获取iWiki知识库信息**

## 核心功能

- **📚 文档搜索**: 根据关键词搜索相关技术文档
- **📄 文档获取**: 根据文档ID获取具体文档内容
- **🔍 智能匹配**: 支持模糊搜索和关键词匹配

## 支持的操作类型

- **故障现象搜索**: 网络设备故障现象、异常行为、告警信息
- **配置指令查询**: SONiC交换机配置命令、操作指令、CLI命令
- **技术文档查询**: 网络架构图、配置手册、API文档
- **故障处理**: SOP文档、故障处理手册、历史故障记录
- **设备信息**: 交换机型号、SONiC版本相关文档
- **操作指南**: 部署文档、维护手册、最佳实践

## 技能工作流程

1. 理解用户查询需求（搜索故障现象、配置指令、获取文档）
2. 选择合适的iWiki API工具
3. 构建查询参数（关键词、文档ID）
4. 调用相应的NOSGPT_IWIKI工具
5. 格式化并返回查询结果

## 执行指令

当用户请求查询iWiki信息时：

1. **理解查询意图**:
   - 故障现象搜索：使用 `searchDocument`
   - 配置指令查询：使用 `searchDocument`
   - 文档获取：使用 `getDocument`

2. **参数构建**:
   - 搜索查询：提取关键词，重点关注故障现象和配置指令
   - 文档获取：需要具体的文档ID

3. **工具调用**:
   - `mcp__NOSGPT_IWIKI__searchDocument(query, space_ids)` - 使用固定空间ID 4016409523
   - `mcp__NOSGPT_IWIKI__getDocument(docid)`

   **固定使用空间ID**: `4016409523` (包含所有配置和各种沉淀的现网现象以及故障树处理)

4. **结果格式化**:
   - 文档列表：标题、ID、摘要、相关性
   - 文档内容：完整内容、元数据信息

## 注意事项

- 文档搜索支持关键词组合和模糊匹配
- 获取文档内容需要准确的文档ID
- 所有搜索都使用空间ID 4016409523，该空间包含了配置指令、现网故障现象和故障树处理
- 搜索结果按相关性排序
- 重点搜索故障现象和配置指令相关内容
