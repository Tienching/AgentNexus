# iWiki Knowledge Retrieval Skill

这是一个专门用于从NOSGPT_IWIKI系统获取知识库信息的技能。该技能可以搜索文档、获取文档内容、查询空间信息等，用于访问网络架构图、SOP、故障处理手册等技术文档。

## 使用方法

1. **调用技能**，告诉我要查询什么信息或搜索什么内容
2. **提供查询参数**（关键词、文档ID、空间名称等）
3. **获取iWiki知识库信息**

## 重要知识库空间

- **4016099810**: SONiC自研交换机配置指导手册空间
- **4012502038**: 自研交换机故障相关空间
- **4012502084**: 端口故障相关空间

**提示**: 搜索时可以指定空间ID来缩小范围，提高搜索精度。

## 核心功能

- **📚 文档搜索**: 根据关键词搜索相关技术文档
- **📄 文档获取**: 根据文档ID获取具体文档内容
- **🏢 空间信息**: 查询iWiki空间的基本信息
- **🔍 智能匹配**: 支持模糊搜索和关键词匹配

## 支持的操作类型

- **技术文档查询**: 网络架构图、配置手册、API文档
- **故障处理**: SOP文档、故障处理手册、历史故障记录
- **设备信息**: 交换机型号、SONiC版本相关文档
- **操作指南**: 部署文档、维护手册、最佳实践

## 技能工作流程

1. 理解用户查询需求（搜索、获取文档、查询空间）
2. 选择合适的iWiki API工具
3. 构建查询参数（关键词、文档ID、空间信息等）
4. 调用相应的NOSGPT_IWIKI工具
5. 格式化并返回查询结果

## 执行指令

当用户请求查询iWiki信息时：

1. **理解查询意图**:
   - 文档搜索：使用 `searchDocument`
   - 文档获取：使用 `getDocument`
   - 空间查询：使用 `getSpaceInfoByKey` 或 `getSpaceInfoByName`

2. **参数构建**:
   - 搜索查询：提取关键词，可选择空间范围
   - 文档获取：需要具体的文档ID
   - 空间查询：需要空间键或空间名称

3. **工具调用**:
   - `mcp__NOSGPT_IWIKI__searchDocument(query, space_ids)`
   - `mcp__NOSGPT_IWIKI__getDocument(docid)`
   - `mcp__NOSGPT_IWIKI__getSpaceInfoByKey(spaceKey)`
   - `mcp__NOSGPT_IWIKI__getSpaceInfoByName(spaceName)`

   **常用空间ID**:
   - 配置指导: `4016099810`
   - 故障处理: `4012502038`
   - 端口故障: `4012502084`

4. **结果格式化**:
   - 文档列表：标题、ID、摘要、相关性
   - 文档内容：完整内容、元数据信息
   - 空间信息：空间描述、文档数量等

## 注意事项

- 文档搜索支持关键词组合和模糊匹配
- 获取文档内容需要准确的文档ID
- 空间查询可以帮助缩小搜索范围
- 搜索结果按相关性排序
- **推荐空间使用**: 对于SONiC相关查询，优先使用空间4016099810；对于故障处理，使用空间4012502038或4012502084
- 搜索时指定相关空间可以显著提高结果准确性和相关性
